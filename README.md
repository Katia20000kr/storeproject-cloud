# StoreProject Cloud Application

This project is a full stack web application developed for the Cloud Technologies Portfolio Assessment.

## Technologies Used

- Python
- Django
- Django REST Framework
- SQLite
- HTML
- JavaScript
- Docker
- Docker Compose
- Nginx

## Main Features

- Product management
- Django Admin panel
- REST API endpoint
- Frontend product list
- Authentication login page
- Dockerized execution
- Nginx reverse proxy
